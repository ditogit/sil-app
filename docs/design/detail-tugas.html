Integrasi API SSO SIAKAD dengan Akun Google Workspace Kampus

Dibuat pada 18 Okt 2024, 09:14 WIB Sprint 4 (Core SI Babarsari) event_busy Tenggat: Kemarin, 16:00 WIB
Deskripsi & Spesifikasi Teknis

Implementasi autentikasi terpusat OAuth2 / OpenID Connect multi-domain (@upnyk.ac.id & @mhs.upnyk.ac.id) untuk mahasiswa baru dan dosen.

Sinkronisasi token session Redis dengan klaster Kubernetes core backend di Kampus Babarsari guna mengeliminasi problem re-login berulang saat pengisian Kartu Rencana Studi (KRS) serentak berskala 22.000 pengguna bersamaan.

verified Acceptance Criteria (Kriteria Penerimaan):
  • Token JWT tervalidasi via RS256 Signature dari endpoint Google JWKS.
  • Waktu respon handshake SSO < 250ms pada P95 latency.
  • Sesi invalidasi serentak (Single Logout) terintegrasi ke seluruh sub-portal UPN.
